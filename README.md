# 김용욱 포트폴리오

13장 PPT를 원본 레이아웃 기반의 HTML로 변환했습니다.

## 미리 보기
압축을 풀고 index.html을 브라우저로 여세요. 이미지와 코드를 포함한 단일 파일이라 인터넷 없이 열 수 있습니다. 목차, 하단 슬라이드 선택, 좌우 방향키로 이동할 수 있습니다. 각 슬라이드 아래에서 원문 텍스트를 펼칠 수 있습니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소(예: portfolio)를 만드세요.
2. 이 폴더의 index.html과 .nojekyll을 저장소 최상위에 업로드하세요. ZIP 자체를 업로드하면 페이지가 열리지 않습니다.
3. Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로 지정하세요.
4. Branch를 main, 폴더를 /(root)로 선택하고 Save를 누르세요.
5. 배포가 끝나면 Pages 설정에 표시되는 주소를 여세요. 일반 프로젝트 주소는 https://<사용자명>.github.io/<저장소명>/ 입니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 변환 특성
슬라이드는 이미지 형태이고, 원문 텍스트는 별도로 펼쳐 볼 수 있습니다. 원본의 Pretendard Variable은 정적 Pretendard로, 맑은 고딕은 Noto Sans CJK KR로 대체되어 일부 줄바꿈이 다를 수 있습니다. PPT의 애니메이션이나 삽입 동영상 재생은 지원하지 않습니다. 화면 너비에 맞춰 슬라이드를 축소하며, 텍스트 재배치형 모바일 웹사이트는 아닙니다.

아직 GitHub에 업로드하거나 공개 배포하지 않았습니다.
